# Weekly cold session

**Two unseen problems, 45 minutes total, once a week.**

Rules: no hints, no editor autocomplete, no notes, talk aloud the entire time as
if an interviewer is listening.

Solving is not the whole score. The rubric below is what an interviewer is
actually grading.

---

## Rubric — score each problem

- [ ] Stated a brute force before optimising
- [ ] Stated time and space complexity, unprompted
- [ ] Dry-ran one concrete example before coding
- [ ] Raised edge cases unprompted (empty, single, duplicates, negatives, cycles)
- [ ] Explained *why* the approach is correct, not just what it does
- [ ] Kept talking while thinking (no silent gaps over ~20 seconds)
- [ ] Code compiled and ran without a syntax fix loop
