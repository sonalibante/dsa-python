# Triggers

The surface signal in a problem statement that should fire a pattern, within
10 seconds of reading it.

Add a row only when a problem teaches a **new** tell. A good trigger is
*discriminative* (it fires on one pattern, not nine) and *generalisable* (it
fires on unseen variants, not just the problem that taught it). Restating what
the problem asks for is not a trigger.

Read this file before an interview. Do not read the solutions.
